## 代码行为

1. 相册入口连接真实系统 Picker，单次最多 20 个项目。串行处理、暂停/继续、单件失败重试/跳过、取消 Picker 保留队列、退出时二次确认。
2. 每件照片必须填写名称/类别并明确确认；颜色和季节可以未知，没有假造 AI 属性。只保存已确认项，每件独立事务，成功项不重复提交。
3. 相同规范化文件 SHA-256 在当前空间中提示重复，包含归档，排除当前编辑对象；提交队列内再次检查，用户明确确认后允许作为另一件保存。不同源 URI 不表示不同照片。
4. 保存、页面关闭和迟到照片结果按媒体所有权收尾，不删除已提交照片；清理失败保留重试状态。单图编辑器关闭等待清理并通知外层刷新。
5. 批量季节支持 `0..15` 所有组合，`-1` 保持不变、`0` 待确认。选择数量上限 200，未知 ID 不进入批量选择。
6. 未保存的导入队列只在内存中，杀进程会丢失未保存属性；已保存记录及照片可恢复。尚无相机、识别/分割、推荐、账号、上传、人像或试穿。

本轮不修改服务端 HTTP 契约、参考 SQL 或 v1 建表资源。仓储接口新增 `hasImageHash`，媒体接口新增 `pickMany`；队列策略写入开发文档第 8 节。
