## 3. 核心验收用例

| 编号 | 操作/输入 | 预期 |
| --- | --- | --- |
| T-01 | 首次启动且不授权相机/位置 | 可体验样例或从允许入口添加，不白屏 |
| T-02 | 5 张导入，其中 1 张不可解码 | 4 张可分别保存，失败项明确可重试/跳过 |
| T-03 | 图片名称伪装成 jpg，或解码尺寸过大 | 拒绝并解释，不崩溃、不大额分配内存 |
| T-04 | 分割服务不可用 | 保留原图，允许人工确认 |
| T-05 | 把外套识别成上衣后人工更正 | 更正落盘，后续按 outerwear 参与规则 |
| T-06 | 同批 3 件衣物改为待洗，模拟写入失败 | 事务整体失败，状态不一半更新 |
| T-07 | 归档、恢复、永久删除 | 归档可恢复；永久删除有确认与引用处理 |
| T-08 | 衣橱混有 demo/personal | 推荐不混入另一空间 |
| T-09 | 候选包含四种不可穿状态 | 全部排除 |
| T-10 | 锁定待洗单品 | 提示冲突，不私自更改状态或解除锁定 |
| T-11 | 缺少鞋履必需槽位 | 返回缺少鞋履，不伪造完整搭配 |
| T-12 | 同一输入运行推荐 10 次 | 同分排序稳定；每套无重复 ID |
| T-13 | 换裤子 | 其他槽位保持；新裤子满足全套约束 |
| T-14 | 季节/适温未知 | 提示确认，不伪称满足所有约束 |
| T-15 | 无穿着日志 | 理由不出现伪造的“30 天未穿” |
| T-16 | 已保存方案的单品被归档 | 历史可看，再次穿着/生成时重新确认 |
| T-17 | 三姿势缺一张或存在重复图片 | 发起前阻断并指出问题 |
| T-18 | 不勾选本次人像授权 | 不发生上传 |
| T-19 | 整套推荐中选择上装试穿 | 设置/结果/导出均说明只替换上装 |
| T-20 | 提交成功但响应丢失 | 同键恢复原任务，配额只扣一次 |
| T-21 | 同幂等键改变图片 | 409，不创建第二任务 |
| T-22 | 查询另一个会话的资产/任务 | 404，无法下载或推断所有者 |
| T-23 | 三图中一张失败 | 已成功两张即时可看，父状态 partial_success |
| T-24 | 重试失败姿势 | 新任务关联旧任务，成功图保留原来源与时间 |
| T-25 | 重新生成视觉异常姿势 | 新种子、新任务、新指纹 |
| T-26 | queued 状态取消 | 不再启动推理，最终 cancelled |
| T-27 | running 时取消与 worker 完成竞态 | 取消接受后的迟到结果不发布 |
| T-28 | 用户取消时三图已成功 | 返回成功状态，不伪称取消成功 |
| T-29 | GPU worker 被杀死 | 租约恢复，重复执行不会重复发布有效结果 |
| T-30 | 任务中杀应用再打开 | 恢复原 ID 和状态，不重新扣生成额度 |
| T-31 | 前台收到比本地更旧 revision | 忽略旧响应 |
| T-32 | HTTP 断开但 GPU 仍计算 | 显示连接问题，不擅自设置远端失败 |
| T-33 | 打开错误输入对应的备用图 | 拒绝匹配，明确无对应备用 |
| T-34 | 相同素材重新上传得到新 asset ID | 内容指纹不因 asset ID 变化而漂移 |
| T-35 | 正确备用图用于演示与导出 | 持续显示备用及时间，不计实时生成成功 |
| T-36 | 输出已过期但本地已保存 | 本地可查看；云下载显示过期，历史状态不被改成失败 |
| T-37 | 离线删除人物 | 本地清理，云端待删状态可见，联网后自动恢复删除 |
| T-38 | 删除时存在运行/重试/复用任务 | 同会话关联闭包清理，迟到结果不重新出现 |
| T-39 | 云删除完成 | 原图、mask、输出、暂存、缓存均不可新访问 |
| T-40 | 删除前先注销 | 明确处理待删队列，不丢掉唯一删除授权 |
| T-41 | 卡片传入不存在衣物 ID | 进入可恢复状态，不崩溃、不越权 |
| T-42 | 字体放大、横屏、软键盘弹出 | 主操作可达，图片与文字不乱叠 |
| T-43 | 保存或分享结果 | 导出图保留 AI 标识和实际替换范围 |
| T-44 | 完全断网 | 本地衣橱、规则推荐、历史及标注备用可用 |
| T-45 | 扫描日志、HAP、备份内容 | 无明文令牌、密钥、无意上传的私人人像 |

## 8. 文档与参考数据库自检

在项目根目录使用可用的 Python 3 执行：

```powershell
python docs/verification/check_docs.py
```

该脚本检查本地链接、代码围栏、JSON 示例、SQL 全新建库以及若干约束和事务场景。它不调用云 API、不执行 GPU、不编译 ArkTS、不连接手机；通过只能说明开发资料及参考 DDL 通过这些检查。
